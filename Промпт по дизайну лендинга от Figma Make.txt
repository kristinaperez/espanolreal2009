
  Build a Spanish language learning web app called Español Real for Russian-speaking users moving to or visiting Spain (A0–A1 level). Tech stack: React + TypeScript + Tailwind CSS v4. Single-page app with state-based navigation (no router needed).

Design system
Font: Montserrat (headings, buttons, labels — weights 700/800/900) + Inter (body text — 400/500). Load both from Google Fonts.
Colors:
Primary: #D32F2F (red)
Primary dark: #B71C1C
Accent (Telegram): #229ED9
Surface: #F9F8F6 (warm off-white)
Card: #FFFFFF
Text: #1A1A1A
Muted text: #6B6B6B
Border radius: 16px for cards, 999px for pills/buttons
Animations: fadeIn (opacity + translateY), scaleIn, shake on wrong answer, celebrate on completion

Key UX requirements
No lorem ipsum — all content is real Spanish phrases with Russian translations
Error messages are warm and encouraging, never discouraging
Words answered incorrectly are flagged for spaced repetition (shown on completion screen)
Progress bar animates smoothly between steps
Every button has hover + active:scale-95 transition
Scrollbar hidden by default
Fully responsive: hero stacks to single column below md breakpoint
