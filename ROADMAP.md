# Teacher Platform roadmap

## NOW
- Phase 1: independent public teacher lesson vertical slice, review PR and accept runtime QA.
- Configure actual demo booking/social destinations on staging; connect a consent-aware analytics collector if measuring leads.

## NEXT
- Phase 2 after Phase 1 acceptance: teacher email authentication and server ownership, dashboard/profile/My Lessons.
- Server-side validated AI draft generation, preview/edit/publish; manual pending/index/noindex and similarity review extension.
- Dynamic sitemap only for approved indexable lessons; real teacher directory.

## LATER
- Phase 3 after usage data: sharing, measured teacher funnels and referral loop.

## BACKLOG
- Phase 4 only if demand is proven: search/filters, availability, reviews, verification, lead management, payments/commission/subscriptions and affiliate system.
