# Доступ, пробный период и окно оплаты — дизайн

Дата: 27.10.2026. Статус: на согласовании у владельца.
Основа: `main` @ 32f8eed (PR #27 «trial-gated monthly access»).
Ветка: `feat/access-1490-paywall-20261027`.

## Цель

Сайт начинает зарабатывать: новый ученик входит через Telegram,
бесплатно проходит первый урок (или пользуется 7 днями), после этого
видит окно оплаты 1490 ⭐ за календарный месяц, поданное через сравнение
«≈ 1 € в день». Мы измеряем, какое сравнение лучше ведёт к оплате.

## Что уже есть в main (#27) и сохраняется

- Пробный период: заканчивается после первого завершённого урока
  или через 7 дней, что раньше. Уроки 2+ требуют Premium.
- На главной нет кнопок оплаты, только текст тарифа.
- Оплата доступна только после окончания пробного периода
  (сервер: `POST /api/payments/telegram/stars` → 409 во время пробы).
- Старые покупки `premium-45` (500 ⭐, бессрочно) сохраняют условия.
- Несколько оплаченных счетов суммируют период; во время активного
  Premium новый счёт не создаётся; возвраты исключаются.
- Публичные страницы уроков показывают описание и 2 фразы-тизера.

## Изменения

### 1. Цена и срок

- 1490 ⭐ (`DEFAULT_STARS_PRICE`, `payments.starsPrice` в
  `data/course.config.json`). Подпись — «≈ 32 € в месяц · около 1 € в
  день» (решение владельца 27.10).
- Основа подписи: цены покупки звёзд в Telegram на iOS, Испания,
  27.10.2026 (скриншот владельца): 1000 = 21,49 €, 250 = 5,39 €,
  500 = 10,90 €. Ближайшая покупка ≥ 1490 ⭐: 1000 + 250 + 250 = 32,27 €.
- Срок — **календарный месяц** вместо 30 дней: оплата 15.11 → доступ
  до 15.12 того же времени. Если в следующем месяце нет такого числа,
  берётся последний день месяца (31.01 → 28/29.02).
- Расчёт по `orders.paid_at`, в UTC. Функция `addCalendarMonth(date)`
  в `src/lib/payments/access.ts` заменяет `ACCESS_PERIOD_MS` в
  `licenseIsActive` и `monthlyExpiry`. Суммирование: каждая следующая
  оплата добавляет месяц к максимуму(текущий конец, paid_at).
- Все тексты с «1790» и «30 дней» берут цену из одного источника
  (`starsPrice()`) и говорят «месяц»: course.config (pricing, FAQ),
  `public-faq.ts`, `terms`, `llms.txt`, `telegram-stars.tsx`,
  `session-summary.tsx`, `settings-view.tsx`, `auth-provider.tsx`
  (FALLBACK_STARS), сообщение 402 в `api/lessons/[n]`, описание счёта.
- Арабская страница аккаунта использует тот же компонент — цена
  меняется и там автоматически; текст про 30 дней на арабском
  заменяется на «شهر» (месяц) — на языковую проверку.

### 2. Обязательный вход до первого урока

- `GET /api/lessons/1` без сессии → 401 «Войдите через Telegram,
  чтобы начать бесплатный урок». Гостевые пробные периоды больше
  не создаются. Старые гостевые записи `learning_trials` с
  `user_id IS NULL` не удаляются; их слияние при входе остаётся.
- Пробный период стартует **в момент первого входа** (регистрации):
  после успешного `POST /api/telegram/auth` вызывается
  `resolveTrial(request, user.id, true)`. Для пользователей,
  зарегистрированных раньше, период стартует при первом входе
  после выкладки (иначе он у них сразу истёк бы).
- В тренажёре: если не вошёл — вместо урока карточка входа
  (существующий `telegram-login.tsx`) с текстом «Первый урок
  бесплатно. Войдите через Telegram — это 1 клик».
- Публичная страница `/lesson/1` (SEO-описание и тизер) не меняется.

### 2а. Карточка входа перед первым уроком

Цель: ощущение, что урок уже рядом, а не форма входа.

- **Львёнок из Сарагосы** (маскот владельца из рилса EspañolReal:
  львёнок с гербом Арагона, реплика «¡Vamos! Пойдём!»). Нужен
  отдельный PNG без фона от владельца; до него — заглушка без
  персонажа. Никаких реальных людей (футболистов и т. п.): в
  Испании использование чужого изображения в рекламе требует
  согласия (LO 1/1982) и выглядит как рекомендация.
- **Превью урока 1**: картинка-ситуация, название и две открытые

- **Бегущая вверх строка «Зачем люди учат испанский»**: короткие
  обобщённые мотивы (список ниже), `aria-hidden` для повторов,

### 3. Сравнения цены

- Список в `data/course.config.json` → `payments.comparisons`:
  `{ id, text, source? }`. Владелец может редактировать без кода.
- Стартовый набор (8):

| id | текст | источник |
|----|-------|----------|
| coffee | 1 € в день — дешевле кофе с молоком в баре | — |
| supermarket | Как один поход в супермаркет: средний чек в Испании — 28 € | Forbes España / AECOC, 2025 |
| menu | Как два menú del día — а практика на целый месяц | Hostelería de España / Edenred, окт. 2026: 14,7 € |
| group | Пять групповых уроков — это около 30 €. Здесь — практика каждый день целый месяц | данные владельца: 6 € за групповой урок |
| cafe | Как один вечер в кафе с другом — только испанский останется с вами | данные владельца |
| netflix | Как Netflix — только вы заговорите по-испански | Kelisto, апр. 2026: Premium 21,99 € |
| gym | Как месяц в недорогом спортзале — только для вашего испанского | cuantomecuesta, апр. 2026: 10–45 € |
| tutor | Как полтора урока с репетитором — а здесь практика каждый день весь месяц | Cronoshare: 15–25 €/час |

- Где показывается: окно оплаты (`TelegramStarsPayment` после
  пробного периода, итоги урока, настройки) и текстовый блок цены
  на главной (без кнопки). Формат: «1490 ⭐ · ≈ 32 € в месяц» +
  строка сравнения.
- Если цена звёзд в Telegram изменится, меняется только текст в
  конфиге (`payments.priceHint`).
- Назначение: **закреплено за посетителем**. Для вошедшего —
  `comparisons[hash(telegramId) % N]`, для гостя на главной —
  случайный индекс, сохранённый в `localStorage` (try/catch,
  без него — случайный при каждом показе). Так видно, какая фраза
  сработала, а не какой был день недели.
- Разнообразие для посетителей обеспечивает число вариантов;
  ежедневная смена фразы для одного человека смешала бы влияние
  фразы и дня. Обновлять можно состав списка (добавлять новые id).

### 4. Измерение

- Клиент: события `paywall_view` и `checkout_click` с параметром
  `variant` в GA4 (`gtag('event', …)`) и цели Метрики
  (`ym(id,'reachGoal', …, {variant})`) — только при согласии на
  аналитику (существующий `consent-analytics.tsx`).
- Сервер: `POST /api/payments/telegram/stars` принимает
  `{ productId, variant }`; `variant` сверяется со списком id
  (неизвестное → `null`) и сохраняется в новое поле
  `orders.price_variant text NULL`. Оплаты по вариантам считаются
  SQL-запросом (будет в docs).
- Миграция `docs/migrations/20261027-price-variant.sql`:
  `ALTER TABLE orders ADD COLUMN IF NOT EXISTS price_variant text;`
  — только добавление, данные не меняются.
- Вебвизор Метрики сейчас выключен (`webvisor:false`). Включение —
  отдельное решение (политика конфиденциальности), не в этой задаче.
- Ограничение: при текущем трафике явный победитель появится
  только после сотен показов окна оплаты.

## Риски

- Обязательный вход может снизить число начавших первый урок —
  это компромисс ради защиты пробы и права боту писать ученику.
  Смотреть долю «зашёл на /learn → вошёл».
- Без миграции новые API падают — порядок выкладки обязателен.
- Цена в евро зависит от курса звёзд; текст правится в конфиге.
